## WØM's role

WØM is **World of Mixologists**: a media/editorial and real-world bar/cocktail-community identity, with `@world.of.mixologists` as an important channel. The newly launched public Bartendly.com ecosystem gateway presents WØM as editorial/community trust, **not** a fourth software app. Bartendly and BBB are the underlying professional/event/mobility/opportunity products. WØM remains distinctive and valuable as its own brand and website.

## Why revisit this site

- Bartendly.com has been redesigned and now runs on Northflank (website repo `bartendly/bartendly.github.io`). Review cross-brand links and positioning.
- Current WØM metadata/body refer to legacy **Bartendly Experiences** as the direct hire-bartender route. Next goal is real **AI-assisted request intake into Bartendly Operations**, spanning weddings, luxury/private events, corporate/trade fairs, Brand requests and industry guest shifts.
- WØM needs a coherent public editorial site that supports real stories/events, media features and partnerships without becoming a Bartendly duplicate or static stale brochure.
